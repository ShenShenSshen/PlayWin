# PlayWin（游窗）v1.0.3

Windows x64 游戏直播客户端。基于 [xiaoyaocz/AllLive](https://github.com/xiaoyaocz/AllLive)，保留 MIT 许可证。项目主页：[ShenShenSshen/PlayWin](https://github.com/ShenShenSshen/PlayWin)。

提供安装版与便携版。v1.0.1 起使用独立 PlayWin 数据路径，不自动导入 v1.0.0 数据，需要重新登录；后续覆盖升级保留 PlayWin 数据。数据统一存储于 `%LOCALAPPDATA%\PlayWin`。卸载安装版会清空全部用户数据。安装包未进行代码签名；网页登录及部分平台请求需要 WebView2 Runtime。

## 编译与发布

安装 .NET 10 SDK 和 Windows 10/11 SDK 10.0.26100.0。在仓库根目录运行：

```powershell
.\build-winui.ps1
```

运行 `artifacts\PlayWin-win-x64\PlayWin.exe`。发布目录包含 .NET、WinUI 和 FFmpeg 运行时；复制整个目录，不要只复制 exe。核心库为 `PlayWin.Core.dll`，资源索引为 `PlayWin.pri`，应用图标为 `Assets/PlayWin.ico`。

开发时打开 `PlayWin.slnx`，项目文件为 `PlayWin.WinUI/PlayWin.csproj` 和 `PlayWin.Core/PlayWin.Core.csproj`。代码命名空间统一为 PlayWin。本地仅保留当前 WinUI 3 工程、核心库及相关测试，旧 UWP 和控制台工程已清理。

## 数据与升级

新版把数据库、设置及日志存放在 `%LOCALAPPDATA%\PlayWin`，应用文件更新不覆盖这些数据。

数据库文件为 `PlayWin.db`，登录、设置、浏览器缓存和更新下载均存放在同一个 PlayWin 数据目录。不再自动读取旧 UWP 数据。

B站登录状态需要在新版重新扫码，随后保存在新版设置中。JSON 收藏仍兼容 Simple Live，导入支持哔哩哔哩、抖音、虎牙和斗鱼，不修改原始导入文件。

当前版本可手动下载安装包覆盖升级，或替换便携程序文件；设置中可检测更新、后台下载安装包，再手动启动安装器。

## 游戏浏览与账号

首页和游戏分类提供哔哩哔哩、抖音、虎牙、斗鱼的平台切换，各自保留游戏分区层级。搜索、关注和历史继续统一。
返回首页保留已加载列表和滚动位置，只核对开播状态；切换平台或点击刷新时重新加载。空列表会区分没有开播房间和网络查询失败。
平台切换使用紧凑的 Fluent 标签按钮，游戏大类标签完整显示并在窄窗口换行。
抖音保留射击、竞技、单机、棋牌、休闲益智、角色扮演和策略卡牌等游戏入口。
首页按四个平台的游戏分区取房间，不回退到娱乐或综合推荐。

首页、分类详情和关注只展示已确认开播的房间，当前页面每 60 秒重新检查；状态无法确认时暂时隐藏。
关注的保存记录不会因停播而删除，刷新或定时重新查询后，重新开播的主播会恢复展示。历史仍保留所有观看记录。
抖音开播状态查询结果复用 30 秒，查询失败不缓存；手动刷新及登录状态变化会清空缓存。

画质选择分别记住 B站和抖音的偏好；房间缺少对应画质时回退到首个可用画质，保留原偏好供其他房间恢复。播放工具栏保留关注和刷新，截图、分享、浏览器和直链放入“更多”。

关注页的“管理全部关注”列出所有保存记录，包括停播主播，可选择取消关注；日常关注列表仍只显示确认开播的房间。

断流先尝试其他线路，再刷新房间状态和播放地址。最多自动恢复 3 次，间隔 2、5、10 秒；确认停播或登录失效时停止，切换直播间及退出播放会取消恢复，最终失败可点击“重新播放”。连续正常播放 30 秒后重新获得恢复次数。
双击视频切换全屏，空格暂停或继续，视频区域滚轮每格调整 5% 音量并保存；鼠标离开视频或静止 5 秒后隐藏播放控件，正在输入或拖动滑块时保持显示。

设置提供 B站扫码登录，以及抖音、虎牙、斗鱼各自独立的官方网页登录。抖音网页完成登录后点击“保存登录”；会话用 Windows 当前用户保护保存，注销会清除应用会话和专用浏览器的 Cookie。
错误提示区分明确的登录失效、网络失败和平台接口异常；网络或平台故障不会删除保存的登录。抖音“登录已保存”表示会话已保存，尚未进行在线验证。
抖音登录和直播请求需要 WebView2 Runtime。接口通过隐藏的官方页面及官网 SDK 签名，复用本程序专用浏览器会话，不再依赖第三方签名服务。平台限制或网络异常时可登录后刷新重试。
后台请求网页禁止媒体播放并拦截媒体下载，仅保留获取直播数据所需的官网签名组件。登录网页保持静音；进入直播间后由原生播放器正常播放音频。

## 浏览快捷入口

记住最后浏览的平台，以及四个平台各自选中的游戏大类；重新启动后恢复。平台分区已移除时回退到当前平台的第一个大类。

在游戏分类卡片上右键选择“固定到首页”，也可以用键盘菜单键或 Shift+F10。每个平台最多固定 6 个游戏，按添加顺序排列；首页只显示当前平台的“常看游戏”，点击进入该分类，右键“取消固定”移除入口。没有固定游戏时隐藏整行。接口失败保留入口，可以重新点击；分类已移除时提示重新选择。

搜索结果显示平台标识，已返回的状态显示“直播中”或“未开播”，未知状态不推断。直播卡片封面统一为 10 像素顶部圆角，悬停标题可以查看全文。

## 检测更新

每次启动主窗口后台查询一次本仓库的 GitHub 最新正式发布，仅发现较新版本时提示“查看更新／稍后”；最新版或网络失败不弹窗。设置的“关于”分组仍提供手动“检测更新”。发现较新版本后可在软件内下载安装包，切换去看直播时下载继续，返回设置可以查看进度或取消；检测失败会区分网络问题、请求受限及发布包异常。

安装包下载到 `%LOCALAPPDATA%\PlayWin\Updates`，以 `PlayWin-版本号-x64-Setup.exe` 保存，大小和 SHA-256 校验通过后才显示“启动安装器并退出”。点击后再次校验并启动安装器，随后退出游窗，由你完成覆盖安装；沿用现有安装标识，升级保留用户数据，卸载仍彻底清空用户数据。检测只接受本仓库对应版本的 PlayWin 安装包。启动会检测，但不会自动下载或安装。

## 播放区域尺寸

在设置中选择 960×540、1280×720、1600×900 或 1920×1080，默认 1280×720。旧的 1280×800 设置自动回退至 1280×720。
尺寸指播放区域的实际屏幕像素，统一为 16:9，不随系统缩放倍数放大。窗口额外补上当前标题栏、工具栏和原生边框的空间，并按当前显示器缩放计算这些空间；浏览页面只预留标题栏。选择立即应用于普通窗口并保存；普通窗口禁止手动缩放及最大化，仍可移动、最小化和关闭。

全屏随所在显示器适配，视频保持比例；置顶小窗固定为 480×270。退出后恢复所选窗口尺寸。
尺寸超出显示器工作区时，扣除工具栏和边框空间后按比例缩小播放区域，不改写保存的选择；移动到另一显示器或显示器缩放变化时重新计算。直播源自身不是 16:9 或已带黑边时仍可能留边，不拉伸、不裁切画面。
主窗口和独立直播窗口分别记住普通模式的位置及显示器；显示器移除或工作区变化后把窗口调整到可见范围。全屏、小窗的位置不覆盖普通窗口位置。

## 自检

```powershell
dotnet run --project tests/WinUIDataCheck/WinUIDataCheck.csproj -c Release
```

自检使用隔离临时目录，验证设置持久化、PlayWin 数据库命名、平台清理、导入过滤及重复启动。

发布后运行 `artifacts\PlayWin-win-x64\PlayWin.exe --smoke-test`，可以检查发布资源、页面、FFmpeg、固定尺寸、全屏/小窗恢复、多窗口同步、位置恢复、有限重试与取消、关注管理、登录错误分类和播放器操作。新增浏览检查覆盖平台和大类恢复、常看游戏的上限与平台隔离、搜索标识及浅深色和窄窗口布局，并启动另一个隔离进程检查设置的重启恢复。测试设置放在独立临时目录，不修改日常设置。结果写入 `%LOCALAPPDATA%\PlayWin\smoke-test.log`，检查完成后程序退出。该检查不等于多显示器、高 DPI 和真实直播断流的人工实测。

更新自检使用模拟响应检查版本比较、正式发布过滤、下载校验、失败清理、取消和跨页面进度恢复，不启动安装器。运行 `PlayWin.exe --smoke-test --update-download-check` 则在独立临时目录下载并校验公开发布的真实安装包，结果写入 `%LOCALAPPDATA%\PlayWin\update-check.log`；该检查同样不执行安装器。





## 界面与播放器

平台切换在首页和分类共用 14 像素圆角外框、10 像素内部按钮，按钮与文字居中；选中使用浅雾蓝底与深蓝文字。游戏大类使用轻标签区分平台导航层级，切换保留 160 毫秒透明度过渡，遵循系统动画开关。

侧栏名称为“首页”“分类”“随便逛逛”。随机浏览按平台等概率挑选，再从该平台游戏首页候选房间中随机选择已开播房间，打开前确认状态。平台失败时尝试其他平台，每个平台最多等待 12 秒；不保证整个平台所有房间等概率。

随机模式提供上一个、播放／暂停、下一个；返回本轮记录，到末尾继续随机，新房间排除已访问记录。确认停播才跳过，网络失败保留当前播放。记录仅在内存中、每个播放器独立；退出后结束。切换在当前窗口内完成并保留窗口模式和音量，历史状态查询最多 10 秒、单次切换最多 60 秒。首个房间禁用上一个，普通打开房间隐藏前后按钮。

播放器操作与关注、刷新合并为一条约 60 像素高的栏，普通窗口在视频下方常驻，跟随主题；窗口内全屏及整屏全屏使用深色磨砂悬浮栏，空闲约 5 秒自动淡出，操作音量、画质、线路或更多菜单时保持显示。关闭系统动画时直接显示／隐藏。窗口内全屏保留标题栏及外框尺寸，Esc 退出当前全屏／小窗模式。

置顶小窗为 480×270 视频区域；悬停时在视频下方展开 44 DIP 操作栏，下方放不下则在上方展开，保持视频位置和尺寸。鼠标移开后收起，菜单操作期间保持展开，恢复按钮可见。

## 磁盘与缓存

窗口位置及音量在停止变化 500 毫秒后合并保存，关闭窗口或离开播放器时补存；其他设置继续即时保存，相同值不重复写入。日志存放在 PlayWin 数据目录的 log 子目录，按天或超过 10 MB 滚动，最多保留 7 份归档、归档不超过 7 天；启动时清理超过 7 天的旧版日期日志。

首页、分类详情和搜索每页最多保留 300 个直播条目，达到上限暂停加载并提示刷新或缩小范围；不删除关注或历史。该上限不是进程总内存限制，视频解码和 WebView2 仍采用组件默认资源策略。
